# ۶. چک‌لیست نهایی + Definition of Done

> ایجنت/توسعه‌دهنده: تا همهٔ ردیف‌ها ✓ نشده، مأموریت «تمام» نیست.
> بازگشت به [`AGENTS.md`](../AGENTS.md) بعد از هر ✗.

## A. سرور (قبل از کدنویسی)

- [ ] `curl ".../api/v2/api.php?app=<SLUG>&only=icons"` → JSON با `icons[]` پر و بدون فیلد `error`
- [ ] `icons_ratio` و `icons_next_slot_in` موجودند
- [ ] اسلاگ اپ در پنل ثبت شده و آیکون فعال دارد (تست `app_not_found` هم بگیر تا خطا را ببینی)
- [ ] `click.php` ریدایرکت 302 می‌دهد (با UA برنامکی — کلیک شمرده نمی‌شود، آمار تمیز می‌ماند)
- [ ] ⚠️ عنوان‌های آیکون‌ها در پنل پر شده‌اند (نه «؟؟؟؟» و نه خالی)

## B. کد

- [ ] `AdManager.kt` کپی شده و فقط `AdsConfig.APP_SLUG` عوض شده
- [ ] `INTERNET` در Manifest؛ coil + okhttp در gradle
- [ ] `AdManager.init(...)` در `onCreate` و `AdManager.onAppForegrounded()` در `onResume` ⭐
- [ ] `AdIconsBanner()` در صفحهٔ خانه + صفحات داخلی (همه از یک کامپوننت)
- [ ] خطای هر نوعی → Hidden و هیچ رندر (تست: فلایتیون/ایرفلاین، اسلاگ غلط موقت)
- [ ] تپ: بازار = `via=app` + باز شدن مستقیم `bazaar://details?id`؛ وب = فقط `click_url`؛ آیتم بدون image رد می‌شود
- [ ] ترتیب آیکون‌ها در هر ورود/رفرش فرق می‌کند (`shuffled`)
- [ ] انیمیشن ورود پلکانی: از چپ به راست، ۱ ثانیه فاصله، fade-in ~۰٫۷ ثانیه؛ با refresh دوباره پخش می‌شود
- [ ] دقیقاً ۳ آیکون در عرض؛ آیتم چهارم با اسکرول راست در دسترس
- [ ] آیکون تبلیغ ۹۰٪ عرض سلول؛ نسبت تصویر از سرور رعایت می‌شود
- [ ] دارک/لایت هر دو چک شده؛ اسکیل واکنش‌گرا روی صفحهٔ کوچک و بزرگ چک شده
- [ ] عنصر بزرگ اپ (لوگو/جدول تزئینی) بنر را از دید خارج نمی‌کند

## C. بیلد و انتشار

- [ ] بیلد با JDK کامل (`javac -version` جواب می‌دهد) — `BUILD SUCCESSFUL` در خروجی دیده شده
- [ ] امضا با همان کلید همیشگی؛ مسیر کلید فقط در `local.properties` (gitignored)
- [ ] اثبات ورود کد به APK: `unzip -p ... classes*.dex | strings | grep -c <ClassName>` > 0
- [ ] `apksigner verify` OK
- [ ] نصب آپدیت روی نسخهٔ قبلی **بدون حذف** موفق (روی یک دستگاه واقعی)
- [ ] push به گیت + اثبات با `api.github.com` و مقایسهٔ git-sha (raw ممکن است موقتاً 404 بدهد)
- [ ] لینک دانلود برای مالک تست شده

## D. QA میدانی (۲ دقیقه روی دستگاه)

- [ ] اپ را ببند و باز کن → بنر می‌آید، آیکون‌ها یکی‌یکی fade-in می‌شوند
- [ ] نت را قطع کن → اپ عادی کار می‌کند، بنر غایب است، هیچ خطایی دیده نمی‌شود
- [ ] نت را وصل کن و به foreground برگرد → بنر طی چند ثانیه/یک رفرش برمی‌گردد
- [ ] روی یک آیکونِ کافه‌بازاری تپ کن → خود اپ بازار باز می‌شود (نه مرورگر)؛ بعد از چند لحظه در پنل، آمار کلیک رشد کرده
- [ ] چند بار وارد صفحات مختلف شو → ترتیب آیکون‌ها هر بار متفاوت است

---

## ✅ Definition of Done

مأموریت وقتی «تمام» است که:

1. همهٔ بخش‌های A تا D تیک بخورند؛
2. مالک بتواند در یک جمله بگوید: «بنر با آیکون‌های تبلیغ در همهٔ صفحات دیده می‌شود،
   ترتیبش هر بار فرق دارد، ورودش انیمیشن دارد، تپش آمار می‌سازد، و وقتی اینترنت نیست اپ بی‌آنکه بفهمم عادی است»؛
3. هیچ قانونی از [`04-golden-rules.md`](04-golden-rules.md) نقض نشده باشد؛
4. کاری که سمتِ مالک است (پنل: ثبت اپ، آیکون فعال، عنوان‌ها) صریحاً به او منتقل شده باشد.
